# BrewPage for n8n: moved

The `n8n-nodes-brewpage` community node now lives in its own repository:
**https://github.com/kochetkov-ma/n8n-nodes-brewpage**.

Install it on self-hosted n8n through **Settings > Community nodes** with the
package name `n8n-nodes-brewpage` ([npm](https://www.npmjs.com/package/n8n-nodes-brewpage)).
Versions up to 0.1.3 were published from this folder; the new repository keeps
their history and publishes every release from GitHub Actions with npm provenance.
