# BrewPage for Mistral Vibe Code

Host HTML pages and static sites, publish AI artifacts, and share Markdown, documents, reports or any file with BrewPage.

See the [bundled installation and compatibility guide](brewpage/README.md). Distribute `brewpage-vibe-1.0.1.zip`; `manifest.json` contains its SHA-256 and file inventory, and `validation.json` records the metadata-only checks and their limits. The unchanged `brewpage-vibe-1.0.0.zip`, `manifest-1.0.0.json` and `validation-1.0.0.json` preserve the earlier artifact and native verification.
