Part of [BrewPage publishing plugins](https://github.com/kochetkov-ma/brewpage-publish-plugins#readme) for [BrewPage](https://brewpage.app).

Host HTML pages and static sites, publish AI artifacts, and share Markdown, documents, reports or any file with BrewPage.

Use [brewpage-vibe-1.1.5.zip](brewpage-vibe-1.1.5.zip) and follow the [bundled installation and compatibility guide](brewpage/README.md). The adapter prefers a compatible BrewPage MCP tool and can select its private local runner before sending a write. [manifest.json](manifest.json) records the SHA-256 and seventeen-file inventory. [validation.json](validation.json) records the 1.1.5 archive and launcher checks. Fresh native loading and publishing remain unverified.

## Historical packages

Versions 1.0.0 through 1.0.6 retain their original ZIPs and matching versioned `manifest-*.json` and `validation-*.json` files. The [1.0.0 receipt](validation-1.0.0.json) records the earlier native verification.
