# BrewPage for Mistral Vibe Code

Host HTML pages and static sites, publish AI artifacts, and share Markdown, documents, reports or any file with BrewPage.

See the [bundled installation and compatibility guide](brewpage/README.md). Distribute `brewpage-vibe-1.0.2.zip`; `manifest.json` contains its SHA-256 and file inventory, and `validation.json` records the 1.0.2 sync checks and their limits. `manifest-1.0.1.json` and `validation-1.0.1.json` preserve 1.0.1. The unchanged `brewpage-vibe-1.0.0.zip`, `manifest-1.0.0.json` and `validation-1.0.0.json` preserve the earlier artifact and native verification.
