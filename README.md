Publish HTML pages, Markdown, files and static sites from AI agents and
automation tools to [BrewPage](https://brewpage.app) and get an HTTPS link back.
No signup or API key. You set how long your publication stays online.

## Integrations

Download the [1.1.2 host packages](https://github.com/kochetkov-ma/brewpage-publish-plugins/releases/tag/v1.1.2)
and verify them against the [asset checksums](SHASUMS256.txt). Qwen and DeepSeek
use `brewpage-mcp@3.0.0` in their default setup.
The Agent Plugin and Antigravity packages share recipes for publishing, Page data,
custom domains and ownership. Both can be installed from a local checkout.

Every package states its pinned host versions, verification records and limits
in its guide. [PROVENANCE.json](PROVENANCE.json) lists the source and release
hashes of the AI-agent packages; the Zapier integration has its own CI workflow
under [`.github/workflows`](.github/workflows), and the n8n node is built and
published from its own repository. These are
independent distributions: a package here does not mean a vendor catalog has
accepted it.

## Code-host catalogs

The repository root carries the publishing skill where code-host skill catalogs
look for it. Both folders are generated by the release tooling from the same
upstream commit as `common/brewpage-publish/`; they differ only in the
User-Agent value.

- `skills/brewpage-publish/`: the eleven canonical files with User-Agent
  `brewpage-gitverse/1.1.2 (+https://brewpage.app)`, the layout of the
  [GitVerse skills catalog](https://gitverse.ru/marketplace/skills) and of
  `npx skills`. The skill uses a compatible connected tool and can run
  `scripts/brewpage-run.sh` with Bash, curl, jq and Python 3 when the host permits HTTPS fallback.
- `.sourcecraft/skills/brewpage-publish/SKILL.md`: a SourceCraft AI skill
  (inputs `path`, `visibility`, `ttl`) that prefers compatible BrewPage MCP with
  the selected owner and verified private result delivery. When permitted, it can select
  protected REST with the same owner before writing. The bundled REST runner sends
  `brewpage-sourcecraft/1.1.2 (+https://brewpage.app)` as its User-Agent. The `upstream/`
  directory contains the runner, recipes and `SKILL.md.source`. The host loads one active `SKILL.md`.

SourceCraft imports a public skill by repository and path in
`.sourcecraft/ai.yaml`:

```yaml
skills:
  - source:
      repo: kochetkov-ma/brewpage-publish-plugins
      path: .sourcecraft/skills/brewpage-publish
```

Neither catalog has listed the skill yet, and no SourceCraft or GitVerse agent
run was performed; the release checks cover the file sets, the SourceCraft
frontmatter and inputs, syntax and the User-Agent values.
